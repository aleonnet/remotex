audio.eld beside this page

One attempt per line: codec description-hex|none sampleRate channels. f8e65000 is the gateway's AudioSpecificConfig (ELD, 48 kHz, stereo, 480-sample frames); f8e64000 is the same with 512-sample frames. The 03… descriptions are that AudioSpecificConfig inside an MPEG-4 ES_Descriptor (the second with its SLConfigDescriptor), which CoreAudio's kAudioFormatProperty_FormatInfo reads as aace where it refuses the bare AudioSpecificConfig: Safari 26.6 passes the description to it as is and, refused, decodes as AAC-LC without the config.
